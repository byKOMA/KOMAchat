Firebase Connection

Where do I get this?
1. Go to console.firebase.google.com and create a new project (free)
2. Left menu → Build → create a Realtime Database → start in test mode
3. Project settings (⚙️) → scroll to "Your apps" → add a web app (</>)
4. Copy the whole firebaseConfig object shown and paste it above (pasting the raw JS code is fine too)
5. The other person needs the exact same values to land in the same room — just share this with them
6. In Realtime Database → Rules tab, set read/write to true (fine since it's a private link only you two know, but keep in mind it's technically a public URL)
